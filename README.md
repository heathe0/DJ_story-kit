# DJ_story-kit

데이터 저널리즘 수업에서 사진, Flourish 차트, 구글 시트 표, 구글 어스 지도, 유튜브 영상, 스크롤리텔링이 들어간 인터랙티브 기사를 직접 만드는 웹 편집기입니다. 설치와 가입 없이 `index.html` 파일 하나로 동작합니다.

## 편집기 열기

GitHub Pages를 켜면 주소 하나로 열 수 있습니다.

1. 저장소의 **Settings > Pages**로 갑니다.
2. Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)`로 고르고 **Save**합니다.
3. 1~2분 뒤 `https://heathe0.github.io/DJ_story-kit/` 에서 편집기가 열립니다.

내 컴퓨터에서만 쓸 때는 `index.html`을 내려받아 크롬이나 엣지로 열면 됩니다.

## 구성

- `index.html`: 편집기 본체
- `manual/사용매뉴얼.docx`, `manual/사용매뉴얼.md`: 학생·교수용 사용 매뉴얼

## 알아 둘 점

- 작업 내용은 각자 브라우저에만 자동 저장됩니다. 다른 컴퓨터로 옮기거나 제출하려면 **작업 파일(.json) 저장**을 하세요.
- 완성한 기사는 **발행하기**로 `index.html` 한 개로 내려받아 Netlify Drop이나 GitHub Pages에 올립니다.
- 올려 쓰는 글꼴은 웹 게시가 허용된 글꼴인지 확인하세요.
