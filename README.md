# DJ_story-kit

Current version: **0.81** ([Changelog](CHANGELOG.md)) · 현재 버전: **0.81** ([변경 이력](CHANGELOG.md))

English · [한국어](#한국어)

## English

A web editor for building interactive data-journalism articles with photos, Flourish charts, Google Sheets tables, Google Earth maps, YouTube videos and scrollytelling. No installation or sign-up: it runs from a single `index.html` file. The editor interface and the published articles can each be set to English or Korean.

### Open the editor

Turn on GitHub Pages to open it from one address.

1. Go to **Settings > Pages** in the repository.
2. Set Source to **Deploy from a branch** and Branch to `main` / `/ (root)`, then **Save**.
3. After 1–2 minutes the editor opens at `https://heathe0.github.io/DJ_story-kit/`.

To use it only on your own computer, download `index.html` and open it in Chrome or Edge.

### Contents

- `index.html`: the editor
- `VERSION`, `CHANGELOG.md`: version number and change history
- `manual/User-Manual.en.docx`, `manual/User-Manual.en.md`: English user manual
- `manual/사용매뉴얼.docx`, `manual/사용매뉴얼.md`: Korean user manual

### Good to know

- Your work is autosaved only in your own browser. To move it to another computer or hand it in, use **Save work file (.json)**.
- Export a finished article as one `index.html` with **Publish**, then put it on Netlify Drop or GitHub Pages.
- Switch the editor language with the **EN | 한국어** button; set the language of a published article in the first field of **Cover and article info**.
- Make sure any font you upload is licensed for web publishing.

## 한국어

데이터 저널리즘 수업에서 사진, Flourish 차트, 구글 시트 표, 구글 어스 지도, 유튜브 영상, 스크롤리텔링이 들어간 인터랙티브 기사를 직접 만드는 웹 편집기입니다. 설치와 가입 없이 `index.html` 파일 하나로 동작합니다. 편집기 화면과 발행 기사의 언어를 각각 영어·한국어로 정할 수 있습니다.

### 편집기 열기

GitHub Pages를 켜면 주소 하나로 열 수 있습니다.

1. 저장소의 **Settings > Pages**로 갑니다.
2. Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)`로 고르고 **Save**합니다.
3. 1~2분 뒤 `https://heathe0.github.io/DJ_story-kit/` 에서 편집기가 열립니다.

내 컴퓨터에서만 쓸 때는 `index.html`을 내려받아 크롬이나 엣지로 열면 됩니다.

### 구성

- `index.html`: 편집기 본체
- `VERSION`, `CHANGELOG.md`: 버전 번호와 변경 이력
- `manual/User-Manual.en.docx`, `manual/User-Manual.en.md`: 영문 사용 매뉴얼
- `manual/사용매뉴얼.docx`, `manual/사용매뉴얼.md`: 국문 사용 매뉴얼

### 알아 둘 점

- 작업 내용은 각자 브라우저에만 자동 저장됩니다. 다른 컴퓨터로 옮기거나 제출하려면 **작업 파일(.json) 저장**을 하세요.
- 완성한 기사는 **발행하기**로 `index.html` 한 개로 내려받아 Netlify Drop이나 GitHub Pages에 올립니다.
- 편집기 언어는 **EN | 한국어** 단추로, 발행 기사의 언어는 **표지와 기사 정보** 첫 칸에서 바꿉니다.
- 올려 쓰는 글꼴은 웹 게시가 허용된 글꼴인지 확인하세요.
